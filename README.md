# Drug Design Project

Fragment-based drug design workflow for identifying and ranking candidate anthelmintic molecules using docking, P2Rank scoring, Foldseek comparison, and post-processing scripts.

![project overview](https://github.com/user-attachments/assets/aa1f8d78-deaa-4169-8f9d-d37394d7f61e)

## Repository layout

```text
Drug-design/
├── data/
│   ├── raw/
│   │   ├── structures/      # Source PDB structures used by the workflow
│   │   └── tables/          # Input CSV tables collected from scoring and analysis steps
│   └── processed/           # Derived CSV outputs generated by the helper scripts
├── results/
│   ├── html/                # HTML visualizations and reports
│   ├── poses/               # Example generated PDB poses
│   ├── text/                # Text outputs from ranking / filtering steps
│   └── tophits/             # Highest-ranked docked structures
├── scripts/
│   ├── bash/                # Pipeline and file-handling shell scripts
│   └── python/              # Data processing and analysis scripts
├── README.md
└── .gitignore
```

## What is in each folder

### `data/raw/structures`
Primary structure files and generated pose examples kept as source/reference material.

### `data/raw/tables`
Input tables used by the ranking and filtering scripts, including P2Rank-related CSV exports.

### `data/processed`
Outputs produced by the Python helpers, such as sorted CSV summaries.

### `results/html`
HTML reports and visualizations generated during the analysis workflow.

### `results/poses`
Example docked poses and generated PDBs.

### `results/text`
Plain-text ranking summaries and helper outputs.

### `results/tophits`
Top-scoring docked structures selected from the workflow.

### `scripts/python`
Python utilities for ranking, filtering, and joining output tables.

### `scripts/bash`
Shell scripts that automate docking setup, copying outputs, and file conversion.

## Main scripts

### Python

- `scripts/python/check_forbidden_fragments.py`  
  Scans docked molecules for forbidden fragments using RDKit substructure and MCS checks.
- `scripts/python/outputtop.py`  
  Joins a ranked score table with comparison results and writes a sorted summary CSV.
- `scripts/python/sortcsvforaf.py`  
  Reads CSVs from `predaf/`, extracts the first score, sorts them, and writes `data/processed/sorted_scoresaf2.csv`.
- `scripts/python/sortcsvforpdb.py`  
  Reads CSVs from `pdbpred/`, extracts score and probability values, and writes `data/processed/sorted_scorespdb.csv`.
- `scripts/python/sortp2rankiwthprob.py` and `scripts/python/sortp2rankprot.py`  
  Additional ranking helpers for P2Rank-style outputs.

### Shell

- `scripts/bash/runag4.sh`  
  Prepares and launches an AutoGrow 4 workflow for a receptor and source compounds.
- `scripts/bash/convert_top_docked.sh`  
  Converts top docked Vina outputs into PDB structures.
- `scripts/bash/copy_top_pdbs.sh`  
  Copies top-scoring PDBs into a dedicated output folder.
- `scripts/bash/copyoutputtop.sh`  
  Copies docking outputs and support files into a GitHub-ready folder.
- `scripts/bash/outputtop.sh` and `scripts/bash/outputtop2.sh`  
  Parse the top lines from generated docking outputs and sort them.
- `scripts/bash/pdbdownlaod.sh`  
  Downloads PDB files from the RCSB service.
- `scripts/bash/copy_to_github.sh`  
  Collects docking results into a folder suitable for pushing to GitHub.

## Dependencies

### Python

- Python 3.10+
- `pandas`
- `rdkit`

Install example:

```bash
pip install pandas rdkit-pypi
```

### Shell tools

Several shell scripts use standard Linux tools and utilities:

- `bash`
- `jq`
- `curl`
- `wget`
- `tar`
- `find`, `sort`, `sed`, `grep`

## Workflow overview

1. Prepare or download the receptor and compound inputs.
2. Run the docking / AutoGrow pipeline scripts from `scripts/bash`.
3. Use the Python helpers in `scripts/python` to sort and merge score tables.
4. Inspect the generated HTML, PDB, and text outputs in `results/`.
5. Keep source inputs in `data/raw/` and derived tables in `data/processed/`.
